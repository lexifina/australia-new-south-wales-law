# 132 Provisions relating to application
For this division-
(a) section 117 applies as if a reference in that section to an application for accreditation were a reference to an application to renew an accreditation, and
(b) sections 118, except subsection (5), 119, 121 and 122 apply as if a reference in those sections to the grant of an accreditation were a reference to the renewal of an accreditation, and
(c) section 120 applies as if a reference in that section to a refusal to grant an accreditation were a reference to a refusal to renew an accreditation.
Note-
A refusal to renew an accreditation is a reviewable decision-see section 676.
