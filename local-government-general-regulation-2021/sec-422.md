# 422 Model code of meeting practice
(1) This section applies if a council fails to adopt a new code of meeting practice that incorporates the mandatory provisions of the revised model code of meeting practice by 31 December 2025.
(2) From 1 January 2026-
(a) a provision of the council's code of meeting practice that is inconsistent with a mandatory provision of the revised model code of meeting practice is void and of no effect, and
(b) the mandatory provisions of the revised model code of meeting practice are taken to form part of the code of meeting practice adopted by the council under the Act, section 360.
(3) In this section-
code of meeting practice, in relation to a council, means the code of meeting adopted by the local council, whether adopted before or after 29 August 2025.
revised model code of meeting practice means the Model Code of Meeting Practice for Local Councils in NSW, published in the Gazette on 29 August 2025.
