# 4 Use of certain land at Salamander Way, Salamander Bay
(1) This clause applies to land at Salamander Way, Salamander Bay, being Lots 50-144, DP 715013, Lots 1-13, DP 734433 and Lot 1, DP 810714.
(2) Development for the purpose of the subdivision of each lot to create 2 lots and the erection of a dwelling house on each lot created by that subdivision is permitted with development consent if a single development application is lodged for such development.
