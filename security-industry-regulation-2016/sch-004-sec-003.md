# 3 Amendment of class 1 or class 2 licences held by existing licence holders
(1) This clause applies to a person (the licence holder) who, immediately before the commencement day, holds-
(a) an existing operator licence, and
(b) a class 1 or class 2 licence.
(2) On the commencement day-
(a) the class 1 or class 2 licence of the licence holder is taken to be amended to add a class 2E licence, and
(b) the existing operator licence ceases to have effect.
