# 15 Notice not required to be in approved form for certain applications
Notice of the following is not required to be given in the approved form-
(a) a development application lodged, but not finally determined, before 30 June 2023,
(b) a modification application if the original development application was lodged before 30 June 2023,
(c) an application for review under the Act, Division 8.2 if the development application to which the review relates was lodged before 30 June 2023.
