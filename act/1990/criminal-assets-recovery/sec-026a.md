# 26A Application for proceeds assessment or unexplained wealth order
(1) The Commission may apply to the Supreme Court under section 27 for a proceeds assessment order or under section 28A for an unexplained wealth order (or for both).
(2) If the Commission applies for both orders against a person, the Supreme Court cannot make both orders, but is to make the order that requires payment of the greater amount.
(3) If the Commission applies for only one of the orders, it may before the application is determined extend the application so that it includes an application for the other order.
