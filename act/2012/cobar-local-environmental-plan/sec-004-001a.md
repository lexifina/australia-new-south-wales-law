# 4.1A Minimum subdivision lot size for strata plan schemes in Zone RU1
(1) The objective of this clause is to ensure that land to which this clause applies is not fragmented by subdivisions that would create additional dwelling entitlements.
(2) This clause applies to land in Zone RU1 Primary Production that is used, or proposed to be used, for residential accommodation or tourist or visitor accommodation.
(3) The size of any lot resulting from a subdivision of land to which this clause applies is not to be less than the minimum size shown on the Lot Size Map in relation to that land.
