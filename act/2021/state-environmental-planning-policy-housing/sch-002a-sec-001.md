# 1 Safety and amenity
(1) The dwelling must be in a building that meets performance requirements set out in the following sections of the Building Code of Australia-
(a) Section B (Structure),
(b) Section C (Fire Resistance),
(c) Section D (Access and Egress),
(d) Section E (Services and Equipment),
(e) Section F (Health and Amenity).
(2) The dwelling must be in a building supplied with the following-
(a) water,
(b) electricity,
(c) sewerage and drainage services.
(3) In this section-
performance requirement has the same meaning as in the Building Code of Australia.
