# 35 Time limit for applications
(1) The time limit for making an application for an administrative review of a decision to take possession of property is 28 days from the date on which the responsible person for the property was notified possession had been taken.
(2) However, if the responsible person for the property is not notified possession of the property has been taken, there is no time limit for making an application for an administrative review of the decision to take possession of the property.
(3) The time limit for making an application for an administrative review of an amount required to be paid for the return of property is 28 days from the date on which application was made for the return of the property.
(4) Subject to section 34(4), this section does not affect the operation of section 32.
