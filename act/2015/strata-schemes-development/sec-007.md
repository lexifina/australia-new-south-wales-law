# 7 Meaning of "subdivision" of a lot or common property
(1) In this Act, subdivision of a lot or common property means the alteration of the boundaries of-
(a) one or more lots to create only 2 or more different lots, or
(b) one or more lots to create one or more different lots and common property, or
(c) one or more lots and common property to create one or more different lots or one or more different lots and common property, or
(d) common property to create one or more lots.
(2) However, subdivision of a lot or common property does not include the consolidation of 2 or more lots into one lot or the conversion of one or more lots into common property.
