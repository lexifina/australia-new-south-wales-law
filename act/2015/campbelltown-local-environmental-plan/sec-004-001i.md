# 4.1I Minimum lot size for certain residential accommodation in Mount Gilead Urban Release Area
(1) This clause applies to land identified as "Mount Gilead Urban Release Area" on the Urban Release Area Map.
(2) Development for a purpose specified in Column 1 of the table to this clause is permitted with development consent on land in the zone specified in Column 2 on a lot that is at least the size specified in Column 3.
(3) Subdivision of land in a zone specified in Column 2 of the table to this clause for a purpose specified in Column 1 is permitted with development consent if the resulting lots will be at least the size specified in Column 4.
