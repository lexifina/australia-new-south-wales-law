# 144I Demerit points incurred for demerit offences-club premises
If the manager of a club premises commits a demerit offence, the following number of demerit points are incurred against the club licence for the club premises-
(a) if the demerit offence is a category 2 demerit offence-2 demerit points,
(b) otherwise-1 demerit point.
