# 152J Offence
(1) A child safe organisation that enters into an enforceable undertaking must comply with the undertaking.
Maximum penalty-
(a) for a corporation-500 penalty units, or
(b) otherwise-100 penalty units.
(2) If a child safe organisation is not a person the reference in subsection (1) to a child safe organisation is to be read as a reference to the head of a child safe organisation.
