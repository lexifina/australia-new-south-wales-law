# 55 Definition
In this division-
relevant standard or code means-
(a) for an activity in relation to an explosive-
(i) AS 2187, and
(ii) the Australian Explosives Code, and
(b) for an activity in relation to an explosive precursor-
(i) Australian Standard AS 4326-2008, The storage and handling of oxidizing agents, as in force from time to time, and
(ii) the ADG Code.
