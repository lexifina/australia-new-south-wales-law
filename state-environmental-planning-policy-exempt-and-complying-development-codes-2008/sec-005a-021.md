# 5A.21 Maximum height
(1) If there is a dwelling on an adjoining lot, the maximum building height for a building is 8.5m.
(1A) If there is not a dwelling on an adjoining lot, the maximum building height for a building is the lesser of the following-
(a) the maximum building height that applies under another environmental planning instrument,
(b) 21m.
(2) The maximum height of any ancillary development must not be more than 5m.
