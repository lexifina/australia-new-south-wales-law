# 5A.3 Development specified for this code
(1) Development for a specified purpose on land in an industrial zone or a business zone is development specified for this code.
(2) Despite subclause (1), development involving the erection of a new building for a specified purpose is not development specified for this code on land in Zone E1, E2, MU1, B1, B2, B3, B4, B8, IN4, SP1, SP3, SP4, SP5 or W4.
(3) Despite subclause (1), development for the purposes of waste or resource transfer stations is development specified for this code only if carried out by or on behalf of a public authority.
