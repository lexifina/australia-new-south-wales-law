# 28 The Code not to be inconsistent with laws applying to plantations
(1) Except as provided by this Act, the Code may not contain provisions that are inconsistent with any Act applying to the carrying out of plantation operations. Any such inconsistent provision in the Code is void.
(2) In particular, the provisions of the Code may not be inconsistent with the provisions of the Protection of the Environment Operations Act 1997 in their application to plantations.
