# 29 Making and amendment of Code by regulations
(1) The Code is to be made by a regulation.
(2) The Code-
(a) does not have any effect unless it is so made, and
(b) ceases to have effect if the regulation that makes it is repealed.
(3) The Code may be replaced or amended by a regulation.
(4) A regulation that makes a Code is not repealed by the operation of Part 3 of the Subordinate Legislation Act 1989.
