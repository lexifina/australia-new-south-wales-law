# 26 "Waste types" and "waste streams"
(1) For the purposes of this Division, the waste type of waste is to be determined in accordance with the Waste Levy Guidelines.
(2) For the purposes of this Division, the waste stream of waste is a reference to the waste stream and (if applicable) waste sub-stream that best describes the source of the waste and is to be determined in accordance with the Waste Levy Guidelines.
