# 58AA Register of persons refused accreditation
For the Act, Schedule 4A, clause 65A(c), the register of persons refused accreditation as accredited certificate providers must include the following information about each person refused accreditation-
(a) the date the person's application for accreditation was made,
(b) the date the person's application for accreditation was refused,
(c) the activities for which the person applied for accreditation.
