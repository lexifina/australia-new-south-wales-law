# 128 Owner's consent for set aside areas (s 60ZC)
Local Land Services is not to issue a mandatory code compliant certificate with respect to a set aside area for native vegetation unless-
(a) in the case of a set aside area on land that is not Crown land-all owners of the land have given their written consent to the establishment of the set aside area, or
(b) in the case of a set aside area on Crown land-the Minister administering the Crown Lands Act 1989 has given the Minister's written consent to the establishment of the set aside area.
