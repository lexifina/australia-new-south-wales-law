# 133 Information required in application for approval by Native Vegetation Panel or modification of approval (ss 60ZH and 60ZI)
An application to the Native Vegetation Panel for approval to clear native vegetation (or for the modification of an approval of the Panel) that seeks to vary like for like credit retirement obligations specified in the biodiversity development assessment report is to include information about the reasonable steps that the applicant has taken to secure the like for like biodiversity credits.
