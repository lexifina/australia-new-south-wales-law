# 11 Existing class 1F licence holders to be issued with class 1C licence
(1) This clause applies to the holder of a class 1F licence that is in force immediately before the commencement day.
(2) The holder must be issued with a class 1C licence that has effect on and from the commencement day.
(3) No application by the holder is required under subclause (2) and no application fee is payable.
