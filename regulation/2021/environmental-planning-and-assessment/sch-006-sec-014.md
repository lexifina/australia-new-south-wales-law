# 14 Compliance with Building Code of Australia
(1) A development application lodged before 1 May 2023 must be determined as if the Planning Legislation Amendment (National Construction Code) Regulation 2023, Schedule 1.3[1]-[7] and [9]-[11] had not commenced.
(2) An application for a complying development certificate lodged before 1 May 2023 must be determined as if the Planning Legislation Amendment (National Construction Code) Regulation 2023 had not commenced.
(3) For an application specified in subsection (1) or (2), a reference to the Building Code of Australia in this Regulation is a reference to the version of the Code as in force when the application was lodged.
