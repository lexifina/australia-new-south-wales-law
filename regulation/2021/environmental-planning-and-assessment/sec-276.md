# 276 Development applications for land in 2 or more local government areas-the Act, s 4.12
(1) This section applies to a development application for development located in 2 or more local government areas.
(2) If a Sydney district or regional planning panel has the function of determining the development application, a separate development application must be lodged with the council for each area in which the development is located.
(3) If a single local planning panel has been established for 2 or more councils, a separate development application must be lodged with the council for each area in which the development is located.
