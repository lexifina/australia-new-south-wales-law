# 232 Model code of meeting practice
The Model Code of Meeting Practice for Local Councils in NSW, published in the Gazette on 29 August 2025, is prescribed for the purposes of the Act, section 360(1).
Note-
See also section 422, which provides for transitional arrangements in relation to the revised model code of meeting practice, including the consequences if a local council fails to adopt the mandatory provisions of the revised model code of meeting practice by 31 December 2025.
