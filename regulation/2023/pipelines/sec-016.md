# 16 Licensee to implement pipeline management plan
(1) The licensee for a pipeline must implement a pipeline management plan for the pipeline if the plan has been given to the Secretary.
Maximum penalty-
(a) for a corporation-10,000 penalty units, or
(b) for an individual-2,000 penalty units.
(2) It is a condition of a licence that the licensee must comply with a pipeline management plan given to the Secretary, as amended in accordance with this division.
